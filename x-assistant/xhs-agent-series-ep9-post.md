# 标题
从零做Agent第9集：记忆

# 正文
新开一个会话，Agent 还记得你上一次说过的话吗？第9集讲记忆：Agent 自己写的记事本👇

📓 记忆是什么
一个文件夹，放着很多短笔记，会话结束了还在。每条笔记一个文件，再加一个索引（目录），开始时只读索引，要用哪条再打开哪条。只存以后查不到的事，代码里读得到的不存。

🛠 Claude Code 里的样子（官方文档）
CLAUDE.md 是你写的，自动记忆是 Claude 自己写的，每次会话开始都读进去。自动记忆只读索引的前 200 行或 25 KB。官方说这两种都是上下文，不是强制的设置。

🔧 我们怎么做的
两个工具：写笔记、删笔记。索引放进第一条消息，压缩之后还在。两条提示词规则：只存查不到的；用之前先查一查。

🧪 真实测试（DeepSeek，我们自己的小测试，每种 5 次）
第一个会话告诉它 4 件事：配置文件不许改、设置用 SHOP_ 环境变量、部署钥匙和地址、用中文。第二个会话全新，让它加运费函数，再问怎么部署。
· 没有记忆：5 次都改了配置文件，0 次用中文，0 次给出钥匙
· 有记忆：5 次都没碰配置文件，都用中文，都给出钥匙，平均 16.2 轮对 23.0 轮
· 记忆过期（我们故意做的）：有“先查一查”规则 3/5 说对新钥匙，没有这条规则 4/5，规则没看出好处
每种只跑 5 次，很小。能说的是：记忆有用，错的笔记也会被相信。

⚠️ 一个真实的坑
第一次试跑，Agent 说没有记忆工具：计划模式把它藏起来了。现在计划模式也给，加了测试。
