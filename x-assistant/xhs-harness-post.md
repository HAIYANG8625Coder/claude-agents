# 标题
AI Agent：产品为什么不是模型？

# 正文
做 AI Agent，真正的产品可能不在模型里，在模型周围那一圈 Harness 里。读完一篇万字长文，挑了 3 个马上能用的点 👇

📖 先认两个词
Agent：能自己调工具办事的 AI
Harness：模型周围的一切，工具、记忆、权限、审批、评测都算
文章打的比方：模型是马，Harness 是马具。马具不会让马更聪明，但能让它真正干活

📌 3 个马上能用的点
① 工具别全塞给模型。接了几千个工具时，别让模型先读完所有说明，让它按任务去找要用的那两个
② 知识按需加载。平时只给名字加一句话，用到了再读全文
③ 高风险操作由系统拦住。弹出真正的「批准 / 拒绝」按钮，不靠模型在聊天里问一句“要继续吗？”

🧑‍💻 我自己的体会
我每天用的 Claude Code 也是这样：技能平时只加载名字和简介，危险操作会先让我确认

💡 文章自己也提醒
只有 5 个工具、任务又短的小应用，直接把工具给模型就够了

我的看法：模型会换，Harness 这一套留得下
