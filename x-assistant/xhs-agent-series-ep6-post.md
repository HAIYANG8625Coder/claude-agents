# 标题
从零做Agent第6集：计划模式和清单

# 正文
Agent 做到第八步，忘了前面的要求，然后说“全做完了”，其实第十二步根本没做。第6集讲清楚两个东西：计划模式和任务清单👇

👀 计划模式是什么
动手之前先只看不改，写出计划，你点头才开始改。像装修先看图纸再砸墙。直接开干理解错了，可能已经改了很多文件；先计划，错了一句话就能纠正。

☑️ 任务清单是什么
把大任务拆成小项，每项三种状态：待做、进行中、完成。像购物清单，买一样划一样。我们的做法里，清单每一轮都摆在 Agent 眼前，还有没完成的项就不让它交最终答案。

🧠 它们怎么帮 Agent
开工前，计划模式管方向；施工中，清单帮它少漏步；收工时，每一项要有能检查的标准。模型没有变聪明，变的是有了一张摆在外面的纸。计划模式的价值，这次没测。

🧪 真实测试（DeepSeek，只是我们自己的小测试）
仓库有 4 个插件、9 个技能、4 个子 Agent，故意放进 12 处违规。任务：提交之前按规则文件检查，全部修好。每改对一处得 1 分，每种设置跑 5 次，满分 60：
· 什么都不加：59 分，平均 15 轮
· 任务清单：60 分，平均 30 轮
· 计划模式加清单：60 分，平均 27 轮
唯一漏掉的一次在“什么都不加”里：漏了一个链接，却说全部符合。5 次太少，不能说清单更准；轮数大约翻了一倍。

⚠️ 两个真实的坑（视频里有出错代码和修好代码的对比）
① 第一版计划模式把读文件也拦了，计划只能盲写
② 计划太长被截断，循环直接结束，5 次里有 2 次一个文件都没改
