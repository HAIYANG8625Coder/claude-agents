# 标题
开源Agent四大流派｜你敢让它跑命令吗

# 正文
你敢让 AI Agent 在你电脑上自己跑命令吗？读了公众号「AI汇览」的一篇文章，它把开源 Harness 分成四大流派，每派都有一处要留意 👇

📖 先认一个词
Harness：模型外面那层软件

🥋 四大流派
① 工位派 OpenHands：管活在哪儿跑
注意：不开沙箱，它就直接跑在你机器上

② 插件派 DSH：官方说“一切皆插件”
注意：卸载插件，撤不回它做过的事

③ 极简派 Pi：核心很薄，故意不做子 Agent
注意：没有内置权限系统，沿用启动者的权限

④ 成长派 Hermes：会从经验里攒技能
注意：这是记忆，不是训练模型，也会记错

💡 文章自己也提醒
这只是一种看法，四派的特点会重叠

🧑‍💻 先说清楚
这四个我都没用过，只是转述文章。我每天用的是 Claude Code，危险操作会先问我
