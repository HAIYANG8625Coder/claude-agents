# 标题
从零做Agent第7集：子Agent

# 正文
Agent 读一个文件，对话就长一截；读了好多个，后面的活都得背着它们。第7集讲子 Agent：它是什么，为什么需要，有没有用👇

🤖 子 Agent 是什么
主 Agent 派出去的小助手：有自己全新的对话，干完一件小事，只把一句结论带回来。像派助手去图书馆，他翻很多本书，你只收一页纸。

⚖️ 好处和代价
好处：主对话保持干净；我们只给它读和搜，改不了东西，更安全。
代价：多花 token。Anthropic 说 Agent 约是聊天的 4 倍，他们的多 Agent 研究系统约 15 倍；带回的一页纸还可能漏细节。

🧪 真实测试（DeepSeek，我们自己的小测试）
任务：从发帖记录里找出 11 月 13 日到 19 日的小红书笔记，共 21 条，打开帖子文件抄下话题标签，做成表存成文件。两种设置各跑 3 次：
· 什么都靠自己：表格对 21/21/20 行，模型调用 34/40/75 次
· 任务里明说让子 Agent 去读文件：表格对 21/20/21 行，模型调用 26/28/33 次
但只有 3 次，子 Agent 第一次没出场，所以不能说它更好。主对话最多才涨到 1.6 万 token 左右，子 Agent 的好处这次没看出来。
