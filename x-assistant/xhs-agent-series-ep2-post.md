# 标题
从零做Agent第2集：工具

# 正文
Agent 为什么能读文件、改代码、跑测试？因为我们给了它工具。第2集给上一集的循环装上4个工具，再看它自己修好一个 bug👇

🧰 四个工具
① read_file：读文件，每行加行号
② grep：用正则搜索，最多返回50条
③ run_bash：执行命令，超时20秒
④ edit_file：把一段旧文字精确替换成新文字，旧文字必须一模一样且只出现一次

🧱 三条设计原则
① 出错别崩溃：把错误写成清楚的话，用 is_error 还给模型。没读文件就想改，我们返回“先读文件”，它自己就去读了
② 返回别太长：超过4000字符就截断，并提示它请求少一点
③ 守住边界：读、搜、改会检查路径在不在项目文件夹里；run_bash 不受这个检查管，真正的权限留到后面讲

📖 对照官方文档
· Claude Code 的 Edit 是精确字符串替换，不用正则，不模糊匹配
· 官方文档里 Bash 输出超过约3万字符，会存到文件，只留预览
· 官方文档里读文件默认不用询问，改文件和执行命令要先问你

🧪 真实运行（deepseek-flash）
· 修 bug：add 函数被写成相减。5轮：ls → 同时读两个文件 → 改 → 跑测试 → 结束，测试全部通过
· 错误恢复：让它不读文件直接改，被拒绝后自己先读再改，成功

⚠️ 三个坑
① 工具太多还功能重叠，模型会选错
② 说明写得含糊，模型不知道什么时候用
③ 参数名含糊（user 还是 user_id）

📝 几点说明
· 屏幕放不下，视频里的工具说明写得比较短；官方文档建议至少写三四句
· 演示用 DeepSeek 的模型，只引用官方文档，没有引用源码
