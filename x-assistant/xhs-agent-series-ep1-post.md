# 标题
从零做Agent第1集：循环

# 正文
Claude Code 为什么能自己读文件、自己做事？因为它背后有一个循环。这个系列从零做一个 Claude Code 式 Agent，第1集用大约50行 Python，把这个循环讲清楚👇

🔁 一轮发生什么
① 把问题发给模型
② 模型不直接回答，回一块 tool_use：请帮我调用这个工具
③ 我们的代码真的去执行，拿到结果
④ 把结果包成 tool_result 发回去，模型再决定继续用工具，还是直接回答
模型自己没有记忆，每次调用都要把完整的 messages 重发一遍

📖 对照官方文档
· Claude Code 官方文档把过程分成三步：收集上下文、采取行动、验证结果，反复进行
· Agent SDK 文档：模型的回复里没有工具调用，循环就结束
· 我们做的是同一个思路的最小版本

🧪 代码和真实运行
· 只有一个工具 list_files，加一个最多跑10轮的保险
· 真实运行（deepseek-flash）：问“这个文件夹里有什么？”，两轮结束，messages 里共4条

⚠️ 三个坑
① tool_result 没发对，API 通常直接报错
② 没有轮数上限，一直跑一直花钱
③ 以为模型自己执行了代码，其实执行的是你的程序

📝 几点说明
· 演示用 DeepSeek 的模型（它兼容 Anthropic 的消息格式），换成 Claude 的 API 只要改一个环境变量
· Claude Pro 订阅不包含 API，要单独在开发者控制台创建密钥
· 讲 Claude Code 的部分只引用官方文档，没有引用源码
