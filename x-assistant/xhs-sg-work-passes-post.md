# 标题
新加坡工作准证全解析2027

# 正文
新加坡工作准证，2027年1月1日起 EP 和 S Pass 的最低月薪要涨了。一次讲清楚：谁能办、多少钱、多久出结果、怎么续签（金额均为新币）👇

📌 最新变化
· EP 最低月薪 5,600 → 6,000，S Pass 3,300 → 3,600（金融业更高）。新申请从2027年1月1日起，续签从2028年1月1日起
· Tech Pass 从2027年1月28日起不再受理，ONE Pass 新增 AI 与科技类别

🧩 三大主力
① EP：月薪线按年龄，30岁现在 7,223、2027年 7,750；COMPASS 满40分，月薪 22,500 以上免打分。申请费105+发证225，约10个工作日。首次最长2年，续签最长3年
② S Pass：2027年起 3,600–5,100，有配额，每月 levy 650
③ Work Permit：没有最低月薪，申请时18岁以上、62岁以下，最长2年，不能带家属

🌟 高端和创业
ONE Pass：月薪3万连续12个月，最长5年，不绑雇主；PEP：月薪22,500，最长3年，不能续；EntrePass：占股至少30%，第一次1年、首次续签1年、之后每次2年

⏳ 短期：TEP 实习准证最长3个月；Work Holiday 18–25岁、最长6个月；Miscellaneous Work Pass 最长60天

👨‍👩‍👧 家属：EP/S Pass 月薪至少 6,000 才能办 Dependant's Pass；父母走 Long-Term Visit Pass，EP 月薪要至少 12,000

🔁 续签：EP、S Pass、家属准证到期前6个月内；EntrePass 3个月；Work Permit 7–12周。不保证批准

📝 说明
· 数据来自新加坡人力部 MOM 和 EDB 官网（2026年11月17日查阅），没讲女佣准证和招聘广告规则
· 不是移民建议，申请前请以官网为准
· 最后一句“先对照新薪水线算一算”是我自己的看法
