# 标题
AI Agent一直在线？5个部件看懂

# 正文
AI Agent 号称 24 小时在线，其实大部分时间在睡觉。Anthropic 11月13日发了篇官方文章，讲这种 always-on agent 怎么搭，我用大白话讲一遍 👇

🔁 一次运行就四步
事件来了 → 醒来干活 → 写回记录 → 接着睡
睡着的时候，一个 token 都不花

🧩 它靠五个部件
① 收件箱：消息、webhook、定时任务、后台任务，先存进一张表排队。一个收件箱同时只开一个 worker，连着几条消息可以合成一次运行
② 闹钟：到点只往收件箱丢一条，不直接开跑。分两种：定期的（比如每天的日报）和跟进的（过会儿看看对方回了没）
③ 记忆：就是一堆文件，只记它自己查不到的。别的系统里有的，存个链接就行
④ 权限：每次调工具，放行、拦下，或者等你点头
⑤ 发件箱：发消息、这次不打扰你，或者先问你一句。文章建议先安静，再慢慢赢得你的注意

⚠️ 文章说风险最大的是权限
它拿着你的权限，没人盯着就在跑。所以密钥不交给它，由 Agent 环境外面的代理来填
