# 标题
Anthropic：Agent记忆怎么做

# 正文
11月6日，Anthropic 官网发了一篇工程文章《The components of agent memory》（Lance Martin），讲怎么给 Agent 做记忆。这期照着原文拆，原图都放在视频里 👇

💡 最反直觉的一点
记得多不等于记得好。宝可梦里，Sonnet 3.7 写了 413 个记忆文件，只拿 1 枚徽章；Fable 5 只写 10 个文件，拿了 4 枚

🧩 六件事
① 记忆分四层：对话记录 → 记忆笔记 → wiki（记忆表示）→ 注入上下文。文章把离线整理这四层叫「做梦」（dreaming）
② 该记什么：CL-Bench 上 Opus 5 有记忆后平均得分 0.564 → 0.828。屏幕上能读到的不用记，只记以后会用到、别处查不到的
③ 怎么引导：只告诉它记忆是干什么的，不教怎么用。固定规则「只记失败」反而让 Opus 5 和 Opus 4.7 丢掉大部分提升；老模型（Sonnet 4.6）多引导，成绩几乎翻倍
④ 做梦·纠错：笔记可能一开始就是错的。拿对话记录去核对，改掉错笔记，Claude 才走出了 Mt. Moon，在第 1,935 步到了 Cerulean
⑤ 做梦·建 wiki：做梦 2 轮到 128 轮，只用 wiki 的得分 13% → 48%；wiki 配搜索 54% → 61%，只用搜索 53%，每题还省约 2 万 token。但单个文档就能答的任务，wiki 没有明显提升
⑥ 做梦·聚焦：几个 Agent 写同一张表互相覆盖，57 条事实只剩 41 条；改成每份合同一页、一个 Agent 写，57 条全部保住
