# Title
从零到1做Agent第9集：记忆｜是什么、为什么、有没有用
# Description
新开一个会话，Agent 就忘了你上次说过的话。这一集从零讲清楚记忆：一个跨会话保存的笔记文件夹。它是什么，为什么需要，再用我们自己的真实任务测一测，最后复习第1到9集。

记忆是什么
一个文件夹，放着很多短笔记，会话结束了还在。每条笔记一个文件，再加一个索引（目录）：开始时只读索引，要用哪条再打开哪条。只存以后查不到的事，代码里读得到的不存。

Claude Code 里的样子
CLAUDE.md 是你写的，自动记忆是 Claude 自己写的，每次会话开始都读进去。自动记忆只读索引的前 200 行或 25 KB。官方文档说，这两种都是上下文，不是强制的设置。

我们怎么做的
两个工具：写笔记和删笔记。索引放进第一条消息，所以压缩之后还在。两条提示词规则：只存查不到的；用之前先查一查。课程大纲里“定期整理旧笔记”这一步，我们没有做。

真实测试（DeepSeek 模型，只是我们自己的小测试，每种设置跑 5 次）
第一个会话告诉它 4 件事：配置文件不许改，设置用 SHOP_ 开头的环境变量，部署钥匙名和地址，以后用中文。第二个会话全新，让它加一个运费函数，最后问怎么部署。
· 没有记忆：5 次都改了配置文件，0 次用中文，0 次给出钥匙，运费函数 5 次都写对了
· 有记忆：5 次都没碰配置文件，都用环境变量，都用中文，都给出钥匙；平均 16.2 轮，没有记忆是 23.0 轮
· 记忆过期（我们故意做的）：有“先查一查”规则，5 次里 3 次说对新钥匙；没有这条规则 4 次。规则没看出好处，说对的都是去读了文档的
每种只跑 5 次，所以数字很小。能说的是：在这个小测试里记忆有用，错的笔记也会被相信。

一个真实的坑
第一次试跑，Agent 说没有记忆工具，什么也没存：计划模式把记忆工具藏起来了。现在计划模式也给记忆工具，并加了一条测试。
