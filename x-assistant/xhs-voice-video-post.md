# 标题
Claude Code做视频｜只给题目

# 正文
在新加坡写代码，这条视频的声音是我克隆的，整条视频是 Claude Code 做的，我只给了一个题目👇

🧰 准备（只做一次）
① 录两分钟自己的声音，只录这一次
② 去 HeyGen 网页手动克隆声音，免费版就行
③ 在 Claude Code 终端版里用 /mcp 登录 HeyGen，桌面版登不上

🎬 之后每条视频
1️⃣ 给 Claude Code 一个题目
2️⃣ 它写两版稿子，我挑一版
3️⃣ 用我的克隆声音生成配音，再放慢 8%
4️⃣ 自动配卡片和字幕，每个字都和声音对上
5️⃣ 渲染完自己检查一遍，发给我看，我点头才发

⏱ 我不用录，也不用剪，一条大概花 10 分钟

💡 HeyGen 免费版用接口克隆会被拒，我试过，要去网页上手动克隆

这套流程我做成了技能 voice-video，开源在 GitHub（claude-agents），建议先收藏⭐
