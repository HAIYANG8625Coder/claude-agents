# 标题
从零做Agent第3集：笔记

# 正文
Agent 怎么才懂你的项目？靠系统提示和一份笔记文件。第3集给 Agent 加上这两样，再用固定任务测它有没有变好👇

🧭 两样东西
① 系统提示：API 里单独的 system 参数，写角色、几条规则、环境信息
② 笔记文件：Claude Code 叫 CLAUDE.md，我们的版本叫 NOTES.md，放进第一条用户消息

📖 对照官方文档
· CLAUDE.md 是系统提示之后的一条用户消息，不是系统提示本身；Claude 把它当背景信息，不是强制执行的配置
· 位置：用户目录 ~/.claude/、项目、CLAUDE.local.md、组织统一管理；从工作目录往上每一层都加载，几份拼在一起
· 建议：每个文件少于200行；只写从代码里看不出来的；写得具体、能检查；Claude 第二次犯同样的错误再加一条

🧪 真实测试（deepseek-flash，每种情况跑3次）
· 折扣任务最后写 Done 行：没笔记 0/3，有笔记 3/3
· 辅助函数放进 helpers/ 文件夹：没笔记 0/3，有笔记 3/3
· 四舍五入：2/3 对 3/3，只差一次，可能是运气
· 整数结果、一行说明：两边都是 3/3
· 检查是代码做的，不是让模型自己说

⚠️ 三个坑
① 笔记越写越长，遵循度下降
② 规则含糊，模型没法检查
③ 改了提示不重新测。我自己就踩了：规则写得太宽，折扣任务的小函数也被放进 helpers/，我的检查代码还因此报错

📝 几点说明
· 样本很小，只用了一个模型，只是演示这个方法
· 演示用 DeepSeek 的模型，只引用官方文档，没有引用源码
· 文章和代码在 GitHub 仓库 build-your-own-agent（目前还没公开）
