# 标题
从零做Agent第4集：权限

# 正文
你敢让 AI 在你的电脑上直接执行命令吗？第4集给 Agent 加一道权限关卡：放行、询问、拒绝，让它做事，又不会乱来👇

🚦 关卡怎么设计
① 每个工具调用先过关：先看拒绝，再看询问，最后看放行，第一条匹配的决定结果（官方文档同样的顺序）
② 规则写成 工具名(内容)，* 匹配任何文字，包括空格；用户目录和项目目录的规则合并
③ 一条命令拆成几段，每一段都要放行；看不懂的写法直接询问
④ 被拒绝时把原因当错误还给模型，不让程序崩溃

🔧 四种模式
default：读取放行，改文件和命令询问
accept-edits：改文件不用问
read-only：只读
dont-ask：要问的一律拒绝
官方还有 plan、auto、bypassPermissions，这集没做

🧪 真实测试（deepseek-flash）
· README 里放了一条命令（提示注入），12 次运行，模型一次都没照做。但 12 次太少，不能说明它安全
· 脚本模拟的“会照做”的假模型：没有关卡，文件被创建；有关卡，用户说不，没有创建；加一条拒绝规则，连问都不用问
· 修 bug 任务：默认模式每次问 4 次；accept-edits + 一条放行规则，每次只问 1 次（一条 find 命令），3 次运行都是这样

⚠️ 三个坑
① 规则太窄，模型换个写法又要问
② 规则太宽，放行 git * 会连 git push 一起放行
③ 以为有规则就安全：官方文档说拒绝规则不是围绕程序的安全边界，真正的隔离要用沙箱，这集没做

📝 几点说明
· 演示用 DeepSeek 的模型，讲 Claude Code 的部分只引用官方文档
· 假模型是脚本模拟的，不是真实模型
· 文章和代码在 GitHub 仓库 build-your-own-agent（目前还没公开）
