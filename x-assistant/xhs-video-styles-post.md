# 标题
Claude Code做视频｜4种风格

# 正文
接着上一条：Claude Code 只给题目就能做视频。可我在 X 上发的两条，几乎长一个样👇

🔍 原因
技能里写着"照着示例视频的样式做"，所以每条都在抄上一条

🎨 现在有 4 种风格
A 市场新闻：浅色报纸底，红绿数字，图表跟着配音长出来
B 屏幕教程：真实录屏，点到哪放大哪
C 大字报：一句一个大字，每段换底色（这条就是）
D 数字人出镜：HeyGen 数字人上镜（要付费版，我还没开）

📌 怎么挑
按题目挑一种，同一个平台不连着用同一种
不变的只有我的克隆声音、片尾签名和结尾的问题

✅ 每种风格都守 4 条规矩
① 主体占满画面，不留大片空白
② 一两秒就有变化：柱子长出来、印章盖下去、硬切
③ 至少两个真实素材：截图、录屏、用真实数据画的图
④ 字幕念配音，卡片放数据，两边不重复

💡 换风格不用重录。视频里左右对比的是同一条英伟达，同一段配音，只换了画面

技能 voice-video 已更新，开源在 GitHub（claude-agents）

四种风格，你最想先看哪一种？
