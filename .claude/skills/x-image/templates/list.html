4 things I learned building my first AI agents

  1. 1
    Start with one agent
    Add a second only when one clearly isn't enough.
  2. 2
    Write the rules down
    Instructions in a file beat explaining every time.
  3. 3
    Add a reviewer
    A second agent catches mistakes the first one misses.
  4. 4
    Keep a human approval
    Anything public waits for my yes.
