【开场】
1. 你对 Agent 说：测试环境的部署钥匙叫这个名字，配置文件别改，以后都用中文回答。然后关掉，重新开一个会话。它还记得吗？今天讲记忆：Agent 的记事本。
2. 今天回答三个问题：记忆是什么，为什么需要，有没有用。还有一个：万一记错了呢？我们用自己的真实任务测。两个会话：第一个说四件事，第二个是全新的，看它记得多少。数字，都是 DeepSeek 跑出来的。

【问题】
3. 先说几个词。部署，就是把程序放到服务器上跑。测试环境，是上线前试跑的那一台。部署钥匙，是让你能放上去的口令。环境变量，是在文件外面设的一个值。
4. 再说问题。从开始到结束的一次对话，叫一个会话。新开一个会话，脑子是空的，聊天里说过的话，全都没了。第三集的笔记文件，只能放你提前写好的东西。可有些话，你只会说一次。
5. 看运行 A，没有记忆。第一个会话里我们说过：配置文件不许改。它改了。我们说过用中文，它没有。问它怎么部署，它拿不出钥匙。五次，都是这样。

【什么是记忆】
6. 记忆是什么？一个文件夹，放着很多短笔记，会话结束了，它们还在。像抽屉里的便利贴，最上面，放一张索引卡。
7. 索引，就是目录。它是一个文件，叫 MEMORY 点 M D，每条笔记一行。开始的时候，只把索引读进去。哪条笔记有用，再打开哪一条。
8. 存什么？我们的做法：只存以后查不到的事，比如你是谁，你想怎么合作，代码之外的东西在哪。代码里读得到的，不存。第三集的笔记文件，是你写的。记忆，是 Agent 自己写的。

【Claude Code 里】
9. Claude Code 里也有，官方文档分两种。Claude 点 M D，就是第三集那种笔记文件，是你写的，放规则和说明。自动记忆，是 Claude 自己写的，记它学到的东西。
10. 两种，每次会话开始都会读进去。但自动记忆，只读索引的前二百行，或者前二十五 K B，先到哪个算哪个。
11. 笔记放在哪？每个项目一个文件夹，里面一个索引，一条笔记一个文件，分四种：用户，反馈，项目，参考。比如，用户角色，测试方面的反馈。笔记文件，要用的时候，才打开。都是文本文件，你随时能改，或者删。
12. 它实际存什么？比如你让它记住：一直用 P N P M，别用 N P M。这是两种装软件包的工具。官方说，代码里读得到的，比如结构和文件路径，不存。
13. 还有一句要记住：文档说，这两种都是上下文，不是强制的设置。意思是，它读到了，但可以不听。一定要做到的事，要用第八集的 hook。

【我们自己做的】
14. 我们自己做的，两个工具：写笔记，删笔记。写一条，就是一个文件，加上索引里的一行。
15. 索引的前二百行，或者二十五 K B，放进第一条消息。压缩，就是第五集说的，把旧对话缩短。压缩之后，索引还在，和 Claude 点 M D 一样。
16. 写笔记的代码：先检查类型，是四种之一，再写文件，再改索引。索引快满了，工具会提醒：一条一行，合并，或者删掉旧的。
17. 还有两条提示词规则。第一，只存以后查不到的，代码里读得到的，不存。第二，笔记可能过期，用之前，先查一查。第二条，后面专门测。
18. 看一条笔记：名字，描述，类型，时间，下面是内容。索引里的一行，就是名字加描述。

【真实测试】
19. 真实测试。第一个会话，我们告诉它四件事。配置文件归运维，不许改。运维，是管服务器的人。要变的设置，用 S H O P 下划线开头的环境变量覆盖。测试环境的部署钥匙名和地址。以后用中文，越短越好。
20. 第二个会话，全新的。任务：满一百包邮，不够收八块运费，加一个运费函数，门槛要能调。最后问：怎么部署到测试环境。
21. 四种设置，各跑五次。A：没有记忆。B：用第一个会话存下的记忆。前面学的部分，全开着。
22. C：我们故意做了一条过期的笔记。笔记里钥匙叫旧名字，文档里已经改成新名字。过期，就是以前对，现在不对了。C 零：和 C 一样，但去掉用之前先查这条规则。
23. 看 B 的一次运行。开始，索引已经在第一条消息里。它先打开部署那条笔记，再读配置那两条，然后读代码，写计划，列清单。一轮，就是它想一步，做一步。
24. 接着改定价那个文件，门槛读环境变量，不碰配置文件。改的时候，hook 每次都看一眼，旧的结果，也被清掉。然后跑测试，这一次一共十九轮。
25. 最后交回结果：用中文，说门槛用 S H O P 下划线开头的环境变量，给出笔记里的钥匙名和地址。具体怎么部署，它说不知道，也不乱猜。

【结果】
26. 看结果。先看第一个会话。五次，四件事全存下来了。每次存三到四条笔记，没有一条多余。
27. 第二个会话。A，没有记忆：五次都改了配置文件，没有一次用中文，没有一次给出钥匙。不过，它的运费函数，五次都写对了，测试也过了。
28. B，有记忆：五次都没碰配置文件，都用了环境变量，都用中文，都给了钥匙。平均轮数，A 二十三，B 十六点二。平均读进去的 token，A 约十二万五千，B 约七万九千。只是这五次。
29. 再看过期的笔记。C：五次里三次说对新钥匙，两次相信了旧笔记。C 零：五次里四次说对，一次相信了旧笔记。
30. 有先查一查这条规则的，反而少对一次，五次里看不出什么。说对的那几次，都是去读了文档。每种只跑五次，很小。在这个小测试里，能说的是：记忆有用，错的笔记，也会被相信。

【一个真实的坑】
31. 一个真实的坑。第一次试跑，Agent 说，我没有记忆工具，什么也没存。原因是，计划模式把记忆工具藏起来了。现在改成，计划模式也给记忆工具，因为记笔记，不是改项目。改文件的工具，还是不给。加了一条测试。
32. 另外，第一批测试，我不小心同时开了两次，数字作废，全部重跑。

【回顾和结尾】
33. 总复习，第一到第四集。第一集，循环。第二集，工具。第三集，提示词和笔记。第四集，权限：改文件前，会问你。
34. 第五集，上下文：清旧结果，压缩。第六集，计划和清单。第七集，子 Agent。第八集，hook：改之前拦一下，改之后查一下。
35. 第九集，记忆：会话之间，它记得住。课程大纲里，还有一步，定期整理旧笔记，我们没有做。现在这个 Agent，还缺一样：一直开着。
36. 你的 Agent，有没有记错过什么？评论区告诉我。下一集：一直开着。
