EP13 把它们接在一起 · 讲稿（共 51 段，卡片编号 = 段号，估计约 740 秒，真实声音大约短 8%）

【开场】
1. 十二集，我们的 Agent 大多是接一个任务，做完就退出。真正能用的工具，是你能跟它聊一个小时的。要把它做成这样，还差什么？
2. 这是最后一集，回答三个问题。还差什么？做完的这个，真的能用吗？Claude Code 有什么，是我们没有的？数字都是 DeepSeek 一个模型跑的，每种五次，很小。我会说清楚，能说什么，不能说什么。

【问题】
3. 先说问题。只接一个任务的 Agent，每次都从零开始。你问完它代码做什么，再问税率在哪，它不记得你刚才问过什么。
4. 我们真测了。四个问题连着问，最后一个是：这次聊天里，你改了哪几个文件？如果每个问题都从零开始，五次里，一次也答不出来。

【是什么】
5. 先把词说清楚。聊天循环，英文缩写 R E P L：读一行你打的字，运行，打印答案，再等下一行。
6. 流式输出。模型写答案的时候，是一小段一小段送过来的。流式，就是收到一段，显示一段，不用等全部写完。
7. 会话，是把整段对话，存成一个文件，下次打开，接着聊。斜杠命令，是一行以斜杠开头的字，它是给程序的命令，不是问模型的问题。
8. 中断，是按 Ctrl 加 C，停掉现在这一轮，但程序不关，聊天还在。

【文章和 Claude Code】
9. Claude Code 官方文档说，它的循环有三步：收集信息，动手，检查结果。三步会混在一起，你随时可以打断。按 Esc，停掉这一轮，已经做完的活保留。
10. 没有任务在跑的时候，按一次 Ctrl 加 C，先清空输入，再按一次才退出。输入可以多行，历史按目录保存。
11. 会话，每条消息，每次工具调用，都写进一个文本文件。有两个开关：一个接上最近一次，一个让你选一次旧的。恢复的有对话历史，模型，权限模式。打断了没跑完的工具调用，不会重跑。文档说，这个文件的格式是内部的，会变。
12. 斜杠命令，文档里有很多个：清空，压缩，看上下文，回退到检查点，都是。文档说，检查点只记文件编辑工具改的文件，不是 git 的替代。
13. 流式，Anthropic 的文档写得很清楚。事件按顺序来：消息开始，每个内容块有开始，若干段增量，结束，最后消息结束。增量，就是一小段一小段新送来的内容。文字走文字增量。工具调用走 json 增量，要攒齐了，再解析。

【我们自己做的】
14. 我们自己做的，先改引擎。运行一次，现在可以接着一个已有的对话。模型调用只剩一个函数，打开流式，就把文字交给显示。Python 的开发包，有现成的文字流，和取回完整消息的函数，循环一行不用改。
15. 第二处，消息改成普通的字典。这样，整个对话直接存成文件，读回来，不用转换。
16. 聊天循环自己，在另一个文件里。每一轮之后，存盘。斜杠命令有十二个。按 Ctrl 加 C，停掉这一轮，保留聊天。
17. 前面十二集的部分，大多数默认开着：权限，上下文管理，任务清单，子 Agent，记忆。hook 和 skill，有对应的文件夹才生效。计划模式，要用斜杠命令打开。M C P，要用一个开关打开。常驻那一集，是另一个不带聊天循环的程序，共用同一个引擎，我们没有把它放进聊天里。
18. 这一集的代码，有三十八项检查，不用 A P I key，就能跑。

【演示】
19. 这是十三集做出来的 Agent，在终端里真实跑一次。下面每一步，都是程序当时打出来的，没有改内容，只缩短了等待模型的时间。
20. 先问一个问题：购物车那个文件，是做什么的？答案一段一段出现，这是流式输出。它先调用了两个工具，看了目录，读了文件。
21. 接着问：税率在哪个文件？我没有再提第一个问题，它还记得，因为聊天是保留的。它去搜索，找到了配置文件。
22. 现在，让它把税率改成百分之八，别的地方也一起改。它先加载了一个 skill，里面是这个项目的定价规则，再读了几个文件。要改文件，或者运行会改东西的命令，它先问我：允许吗？我选，这次聊天里一直允许。它改了配置，说明文件，更新日志，还写了测试，最后运行测试，全部通过。
23. 再问：这次聊天里，你改了哪些文件？它答对了：配置，说明，更新日志，和测试。如果每个问题都从零开始，它是答不出来的。
24. 现在试中断。我让它读所有的 Python 文件，它要运行命令，我同意。然后，我按 Ctrl 加 C。这一轮停了，屏幕上写着：已停止。聊天还在。
25. 马上再问：现在的税率是多少？它答：百分之八。聊天没有坏。
26. 输入斜杠 context，看对话：三十六条消息。然后退出。
27. 再开一个全新的进程，接上上一次的聊天。
28. 问：你先读的是哪个文件？它记得：购物车那个文件。因为整个对话，存在文件里，下次可以接着聊。
29. 这就是十三集做出来的 Agent：一个循环，一些工具，几道边界。

【真实测试】
30. 接下来是真实测试。四个问题，连着问，在同一个小商店项目里。代码做什么。税率在哪个文件。把税率改成百分之八，别的地方也改。最后：这次聊天里，你改了哪些文件？
31. 两种做法。聊天保留，和每个问题都从零开始。看三件事：税率改对了没有，最后那个问题答对了没有，读了多少 token。token，是每一轮读到的内容，加起来，每一次模型调用都算。
32. 第二个测试，流式。问一个不用工具的问题，量从发出，到屏幕上出现第一个字，多少秒。流式和不流式，轮流跑，每种五次。
33. 第三个测试，中断。在第一个工具调用出现的时候，按 Ctrl 加 C，再问一个问题。分两种：有修复，和没有修复。修复是什么，后面讲。这里的按键，是代码模拟的，真的按键没法写进脚本。模拟的是最常见的一种：工具调用刚出现，结果还没来。其他时刻按键，我们没测。
34. 第四个测试，恢复。开一个聊天，退出。再开一个新的进程，接上上一次，问：你先读的是哪个文件？

【结果】
35. 看结果。第一个测试。税率，两种做法，都是五次全对。最后那个问题，保留聊天，五次全对，每个问题都从零开始，零次。这一条很明显：它不可能知道。
36. 再看第二个问题，税率在哪。保留聊天，平均用二点四次工具调用，从零开始，四点六次。大概是因为，保留的聊天里，已经读过相关的文件，这一步是我的推测。
37. token。读掉的总数，保留是十万零一千一百零五，从零开始是八万八千四百二十五。可是每次差得很大，最少五万九千五百三十三，最多十五万三千五百零九。所以，不能说保留聊天更费，也不能说更省。
38. 流式。屏幕上出现第一个字，流式平均五点一秒，不流式七点零四秒。流式这五次，从小到大是：零点六九，四点四一，六点四六，六点六四，七点三。我的判断是，模型先想了一会儿，才开始写字。每一次和它自己的结束时间比，早出现一到七秒。可是整段写完的总时间，流式没有更快：七点四四，对七点零四。
39. 中断，有修复，下一个问题答对了，五次里四次。没有修复，零次，五次全被接口拒绝。恢复，新进程里接上，答对，五次。五次，一个模型，我们自己的小项目。

【真实的坑】
40. 一个真实的坑。按 Ctrl 加 C 的时候，对话停在半路：模型要调用一个工具，工具的结果还没来。下一个问题发出去，接口直接拒绝，说有工具调用，没有结果。整个聊天就死了。
41. 修复很短。下一个问题之前，把这一轮收尾：每个没跑完的调用，补一个结果，被用户停掉了，再补一句助手的话。这样，每个调用都有结果。
42. 还有两个小的。第二个，没修好：五次里有一次，模型把“被用户停掉了”，当成了最后的答案，大意是，我不知道，没有再去看一次。第三个，是我们跑真实测试之前，自己发现的：关掉流式的第一版，一个字也没打印。

【总复习与结尾】
43. 总复习。第一集，循环。第二集，工具。第三集，提示词和笔记。第四集，权限。第五集，上下文。第六集，计划和清单。
44. 第七集，子 Agent。第八集，hook。第九集，记忆。第十集，常驻。第十一集，M C P 和 skill。第十二集，测试。第十三集，把它们接在一起。
45. Claude Code 有的，我们没有。一，系统层面的沙箱，文档说默认不开，要自己打开：写文件限制在工作目录，网络要过白名单。我们的权限，只决定命令跑不跑，不管它跑起来能碰什么。二，自动权限模式，由另一个模型审查。三，子 Agent 是文件，有自己的工具，模型，和记忆。
46. 四，检查点，和回退。五，会话选择器，和分叉对话，我们只有保存，和接上。六，更完整的输入编辑，我们只有最基本的历史，和多行。七，很多命令，企业的统一设置，云端会话。接下来可以做的：更难的测试题，一个沙箱，一个真正的终端界面。

【系列结尾】
47. 十三集做完了。你手里有一个自己写的命令行 Agent，一千四百八十六行代码，含注释和空行：引擎，聊天循环，和 M C P 客户端。它读写文件，问权限，管上下文，派助手，记事情，接别人的工具，还有一套测试它的办法。
48. 这十三集，我想让你带走的，不是这一个 Agent，是它的骨架：一个循环，一些工具，几道边界。后面的，都是接线。你可以自己读懂，也可以自己改。
